預覽產出的 App
推薦 用分享連結直接傳給旅伴
免註冊、免部署：產生連結 → 貼到 LINE → 旅伴點開就能看、可改但只存自己手機（不同步）。
怎麼運作？行程內容就完整儲存在這串專屬連結裡，旅伴點開就能直接看，完全不經過外部伺服器，安全又有隱私，密碼保護也照常生效。
行程有變動？回來改好，重新按「產生分享連結」，把新連結傳給旅伴蓋掉舊的。
連結的壽命，綁在這個網站上
連結靠這個網站（旅人手帖）顯示行程——萬一哪天網站收掉或網域到期，連結就會打不開。 想長期保存、不依賴任何人？改用進階模式 → 下載 + 部署，把行程放進你自己的空間（例如免費的 Netlify）。
進階選項 需要多人即時同步、想自己架站、或想加到手機桌面當 App 用？
多人即時同步（Firebase）
啟用後，行程協作編輯、注意事項、集合倒數、費用分帳會即時同步到每個人的手機。只在「下載 + 部署」模式生效，分享連結模式不啟用。
這三步是第一次設定才要做。之前已經設定過、現在只是要改內容重新部署，直接看本區塊最後的「之後要改內容？」。
第一次設定（三步）
1
建一個資料庫。開啟 Firebase Console →，「建立專案」輸入名稱（例 tokyo-trip-2027），問到 Gemini、Google Analytics 都選「不啟用」。進專案後，左側「資料儲存空間」→「Realtime Database」（找不到就用上方搜尋列搜 Realtime Database）→「建立資料庫」→ 位置選「新加坡（asia-southeast1）」→ 安全性規則選「以鎖定模式啟動」（別選測試模式，它 30 天後會自動鎖上、旅伴會連不上）→「啟用」。
✓ 完成：你有一個資料庫了。
2
把資料庫只開放給這趟旅程。切到上方「規則」分頁，整段換成下面這段，按「發布」。這段只開放你旅程代碼的空間、沒有期限。 

            
            
✓ 完成：「規則」分頁顯示你的代碼，狀態為已發布。

          

        

        

          
3

          
把資料庫接到這個生成器。左側「設定 ⚙」→「一般」→ 捲到「您的應用程式」→ 點網頁圖示 </>，暱稱隨意（例 trip-app）、不用勾 Firebase 託管 →「註冊應用程式」。畫面會出現一段含 firebaseConfig 的程式碼，整段複製、貼到下方欄位（系統自動取需要的部分），按「測試連線」。
            
✓ 完成：看到「✓ Firebase 連線成功」就設定好了。

          

        

        

          
          
        

        
        

      

    

  


  

    
下載 + 部署

    

      適合：需要 Firebase 多人同步、想要自己掌控的獨立網址、想把 App 加到手機桌面用。
    

    

      
    

    

  


  

    
部署到網路

    
把 zip 解壓縮後整個資料夾上傳，旅伴就能在手機上打開。

    
    
      
  1. 1
    解壓縮下載的 .zip，會得到一個資料夾，含 index.html、manifest.json、sw.js 三個檔案。
    2. 
      
  2. 2
    前往 netlify.com 註冊（用 GitHub 或 Google 都行），免費。
    3. 
      
  3. 3
    登入後在左側點「Projects」，把解壓縮出來的資料夾拖進頁面最下方的拖放區（寫著「Drag and drop your folder here」，或點旁邊的「choose a folder」選取）。請拖資料夾、不要拖 .zip。部署完成後，Netlify 會給你一個網址（https://xxx.netlify.app）。
    4. 
      
  4. 4
    網址預設是隨機名（如 bejewelled-souffle-46181b），趁分享前先改好記一點：進這個 Project →「Project configuration」→「General」→「Project details」→「Manage project name」，改成像 claire-tokyo-2027，網址就跟著變短。（只能用小寫英數字和連字號、要沒被別人用過；改名後舊網址會失效，所以先改再傳）
    5. 
      
  5. 5
    把網址傳給旅伴。在手機上打開 → 加入主畫面，就像 App 一樣使用。
    6. 
    

    

      ☁ 天氣預報自動運作。App 部署後會從 Open-Meteo 抓未來 16 天的天氣，免費、不需設定。旅程開始日距今超過 16 天時顯示「尚無預報」，越接近出發越準。
    

  


  

    
之後要改內容？網址不用換

# 景點時間欄位：恢復時間選擇器（驗收條件，站①）

> 狀態：已確認（2026-10-17，Claire 確認：產生器一起改、示範行程同步）。

## 背景

- 旅伴在行程 App 裡「新增／編輯景點」的時間欄位，原本是手機原生的時間選擇器（可轉盤挑時間，見 Ado 行程截圖）。
- 2026-09-17 為了修「時間是『夜』『9:00』這類非標準文字時，打開編輯表單一存檔就被清空」，改成一般文字框＋數字鍵盤（舊 repo commit `5b02040`，搬到本 repo 後沿用）。
- 副作用：Android 的數字鍵盤沒有冒號，旅伴打不出「08:00」，也沒有選單可以挑（吉隆坡行程截圖，只能打成「800」）。
- 這次要兩件事都成立：**能用選擇器挑時間**，而且**非標準文字不會被清空**。

## 做法（給 Claire 判斷用的白話說明）

- 時間是空白或「時:分」格式 → 顯示時間選擇器。「9:00」這種少一位數的，自動補成「09:00」再放進選擇器。
- 時間是「夜」「上午」這類文字 → 顯示原本的文字（一般鍵盤，可以打中文和冒號），旁邊有「改用時間選擇器」按鈕；不按就原樣保留。

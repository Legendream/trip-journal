# 驗收條件：視覺減量（emoji 收斂與對比修正）

> 狀態：已確認（Claire 2026-10-12）｜依據：`docs/design-handoff/group-trip/PROGRESS.md` 下一步第 4 項、`docs/design-handoff/visual-cleanup/backlog.md`
>
> 開發五站的站①產物。實作在分支 `fix/pwa-scope-per-trip`，與下一步 1、2、3 同一包 PR。

## 範圍

- **做**：拿掉介面上裝飾用的 emoji；日卡主題 emoji 改成只在收合時顯示；修四處文字對比不足。
- **範圍**：行程 App（`generator/template-src.html` 與建置產物 `generator-template.js`、示範頁 `trip-app-v2/`）、產生器（`generator/index.html`、`generator-app.js`、`group-ui.js`）。
- **不做**：落地頁 `index.html`、檢視器外殼 `v/index.html`、行程海報與單日小卡的畫面、AI 提示詞（`PARSE_PROMPT`）、琥珀黃主題主色本身。

## 設計決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | 原則：emoji 是「資料」就留，是「介面」就拿掉 | Claire 2026-10-12 同意 |
| 2 | 介面 emoji 直接拿掉、只留文字，不改線條圖示 | 文字已說明；補一套圖示工作量大 |
| 3 | 日卡主題 emoji：日卡收合時顯示，展開後隱藏；資料與海報不動 | 展開後已有活動圖示，避免兩層 |
| 4 | 行程 App 與產生器一起做 | Claire 決定 |
| 5 | 對比修四處：集合按鈕、集合橫幅、時間標籤、住宿未訂小標籤 | 同一包處理；集合橫幅是盤點時新發現 |
| 6 | 時間標籤與未訂小標籤用「主題主色混入 #1e0d12 35%」的加深色 | 沿用分組標籤已定案的算法（decisions.md） |
| 7 | 集合按鈕、集合橫幅底色不變，只把白字換成深色字 | 集合本來就該跟主題色區隔，改動最小 |
| 8 | 旁邊沒有文字、單獨當標籤用的 emoji 這包不動（清單見下） | 拿掉就沒有標示，要換成文字得重排版面；另記 backlog |

### 留下來的 emoji（資料或有功能）

- 成員頭像，以及沒有頭像時的預設符號（👤、💬）
- 活動圖示（含預設 📍、住宿 🏨、航班 ✈️）與新增景點表單的圖示選擇列
- 交通類型符號（程式用來判斷是否顯示停車按鈕）
- 注意事項圖示（含預設 ⚠️）與圖示選擇列
- 天氣符號
- 日卡主題 emoji（資料保留；產生器的輸入欄位保留）
- 狀態符號：⚠️、✅、⏳
- 系統通知標題「🔔 集合時間到！」（不在 App 畫面內）
- 行程海報與單日小卡上的 emoji

### 這包不動的單獨標籤（決定 8）

- 行程 App：只有圖示的編輯鈕 ✏️、加照片鈕 📷、集合時間列的 ⏰、訂位資訊前的 📋、地點前的 📍（集合訊息、購買地點）、記帳備註前的 📝，以及說明文字裡提到的「✏️」「📍 地圖」
- 產生器：景點列的 📍、📋 欄位標示、逐景點 🅿️ 開關、選單的 ⬇ ⬆

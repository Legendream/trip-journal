# 品牌名稱在手機上不斷行（驗收條件，站①）

> 狀態：已確認（2026-11-15 Claire 同意照建議處理）。

## 背景

- Claire 回報：手機上首頁頂部、首頁大標題、產生器頂部的「旅人手帖」被拆成兩行（例：「旅　人／手　帖」、「旅 人 手／帖」）。
- 原因：三處都寫成「旅　人　手　帖」，字中間是全形空白（U+3000），加上拉開的字距；瀏覽器會在空白處換行，窄螢幕放不下就斷開。
- 決定：只修斷行（維持現有雜誌風的外觀）；首頁要不要改成靠左排版，另外用 Claude Design 做樣稿比較後再決定。

## 驗收條件

| # | 情境 | 預期行為 |
|---|---|---|
| W1 | 手機（375px、320px 寬）看首頁頂部小標誌 | 「旅　人　手　帖」一行顯示，不擠到右邊的「免註冊・完全免費」與按鈕 |
| W2 | 手機（375px、320px）看首頁大標題 | 一行顯示、不超出畫面、不出現橫向捲動 |
| W3 | 手機（375px、320px）看產生器頂部標題 | 一行顯示，不擠壞右邊的旅程名稱 |
| W4 | 桌機寬度 | 三處外觀跟現在一樣 |
| W5 | 三支檢查 | 都通過（這次只改首頁與產生器的 CSS，不動樣板） |

## 驗證結果（2026-11-15，站③）

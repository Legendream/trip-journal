# 景點圖示改成固定分類＋可自訂；移除每天的 emoji（驗收條件，站①）

> 狀態：已確認（2026-11-13 Claire 定案：六大分類＋使用者自選）；已實作並驗證（見文末）。

## 背景

- 使用者抱怨：整理行程後的 emoji「種類很怪、常常不是我要的」。
- 查到的現況：
  - 每天的 emoji、每個景點的圖示，都由 AI 從所有 emoji 任意挑（整理指令「為每天主題挑一個合適的 emoji」「acts 內每個活動的 icon：挑合適的 emoji」）。
  - 每天的 emoji 在產生器、行程 App 都改不了；景點圖示在產生器第 2 步是一個要自己打 emoji 的小文字框。
  - 行程 App 新增景點的圖示選單 = 這趟已用過的圖示＋一組預設，會把 AI 挑的怪圖示帶進來。
  - 程式有用圖示做判斷：交通圖示不顯示停車按鈕（`isTransit`）、班機／列車要提醒填時間（`needsTime`）、🚗🚙 認出租車（`fromLegacyDay`）。
- 決定（2026-11-13）：景點圖示改成**一套固定分類（MECE）＋使用者可自訂**；每天的 emoji 移除。

## 分類（MECE）

分法：依「這個時段主要在做什麼」分成 6 大類，大類之間互斥、合起來涵蓋所有行程項目；交通再依交通工具細分（程式要靠它判斷停車、時間）。

| 大類 | 分類 | 圖示 | 涵蓋 |
|---|---|---|---|
| 移動 | 飛機 | ✈️ | 班機、機場報到 |
| 移動 | 鐵路 | 🚆 | 火車、新幹線、高鐵、地鐵、電車、纜車 |
| 移動 | 巴士 | 🚌 | 公車、客運、接駁車、觀光巴士 |
| 移動 | 船 | ⛴️ | 渡輪、高速船、遊船 |
| 移動 | 汽車 | 🚗 | 自駕、租車取還車、計程車 |
| 住宿 | 住宿 | 🏨 | 入住、退房、寄放行李 |
| 飲食 | 用餐 | 🍴 | 早午晚餐、小吃、夜市、居酒屋 |
| 飲食 | 咖啡甜點 | ☕ | 咖啡廳、甜點、下午茶 |
| 遊覽 | 文化歷史 | 🏛️ | 寺廟、神社、博物館、古蹟、老街 |
| 遊覽 | 自然戶外 | 🌲 | 公園、步道、健行、海邊、賞花、展望台 |
| 遊覽 | 體驗娛樂 | 🎟️ | 樂園、表演、演唱會、溫泉、手作、導覽行程 |
| 購物 | 購物 | 🛍️ | 商場、藥妝、市場採買、伴手禮 |
| 其他 | 其他 | 📍 | 集合、辦手續、換錢、不屬於以上的 |

**分界規則**（給 AI 和使用者判斷用，避免一件事能放兩類）：
- 依「主要目的」選一類：夜市逛吃 → 用餐；市場採買 → 購物。
- 搭交通工具去某地：那段移動是「移動」；到了之後做的事另算一項。
- 溫泉、表演、導覽行程算「體驗娛樂」；只是走走看風景算「自然戶外」或「文化歷史」。
- 判斷不了 → 其他。

## 第二輪調整（2026-11-15，Claire 確認）

背景：使用者看不懂「體驗娛樂」這類細項名稱；Claire 決定介面只顯示大類、使用者在大類裡自己挑 emoji，並擴充清單。另一併修正整趟海報的網址列。

決定：
- 一份精選清單，AI 和使用者共用；擴充成 41 個。
- 介面只顯示大類名稱，按鈕只有 emoji（細項名稱只給 AI 看，並當作無障礙標籤）。
- 「移動」改名「交通」；最後一類是「自訂」，可放任何 emoji。
- 整趟海報下方的網址列（網址＋「複製連結」）整列移除。

# 行程海報（Showcase Poster）改版 brief — 給 Claude Design

> 搭配同資料夾的 `current-poster.html`（現況 1:1 重現＋壓力測試案例）一起上傳。

## 這是什麼

旅人手帖（trips.claire-cheng.com）行程 App 裡的「製作行程海報」功能。使用者把自己的行程做成一張直式圖片，
分享到 IG 限動、LINE、FB 給**沒有同行的朋友**看。圖片底部有 QR code 導回旅人手帖首頁（拉新用）。

三種版面：
1. **單日・無照片**：某一天的主題、日期、景點清單、住宿、一句話（選填）
2. **單日・有照片**：同上，上方 46% 放使用者照片
3. **整趟**：每天一行（D1 ✈️ 4/15（三）抵達仙台）

## 要解決的問題

1. **字太小**：畫布 720×1280，內文只有 15px。圖片在手機上全螢幕看時（390pt 寬）會縮成 0.54 倍，
   內文實際只有約 **8pt**（iOS 內文標準是 17pt）。見下表。
2. **下方大片空白**：單日無照片版的內容在 y=265 就結束（只用了 1280 高度的 21%）；整趟 8 天版在 y=562 結束（44%）。
   footer（y=1160）之前的空間都空著，字卻很小。應該讓字放大填滿空間。
3. **對比不足**：背景漸層右下角 `#e06a8a` 上的白字對比只有 3.18:1；85% 透明度的次要文字只有 2.72:1
   （WCAG 小字要 4.5:1）。
4. **資訊層級弱**：標題、日期、景點、住宿的大小差距太小，看起來都差不多。

## 設計限制（很重要，請務必遵守）

這張圖**不是 HTML 截圖**，是用 **Canvas 2D API** 一筆一筆畫出來的，而且內容由每個使用者自己的行程決定。
設計稿必須能被翻譯成 canvas 繪製程式：

- **畫布固定 720×1280（9:16）**，輸出時 2 倍解析度（1440×2560 PNG）
- **字型只能用系統字**：`-apple-system, "PingFang TC", "Hiragino Kaku Gothic ProN", "Noto Sans CJK TC"`。
  不能載入 web font（使用者可能離線，canvas 也不會等字型載入）
- 可用效果：純色／線性漸層、圓角矩形、半透明、圖片 cover 裁切、文字。
  **避免**：模糊（backdrop blur）、陰影層疊、複雜遮罩、SVG 插圖、裝飾字體
- **主題色會變**：每趟行程有自己的主題色（這張是粉紅 `#c94b72` → `#e06a8a`），也可能是藍、綠、棕等。
  文字色要在任何中等深度主題色上都讀得清楚（可考慮加深背景、或在文字區加深色底）
- **內容長度不固定**（見 HTML 裡的壓力測試）：
  - 單日景點 1～8 個以上，名稱可能很長（日文、中英混雜）
  - 整趟 2～20 天以上，每天都要塞得進一張圖
  - 住宿可能沒有；一句話選填、上限 20 字；照片選填
  - 設計要說明「內容多時怎麼縮」（例如字級下限、改兩欄、超過 N 個顯示「＋3 個景點」）
- emoji 會出現在資料裡（每日 emoji、🏨），目前是系統 emoji 字型繪製
- footer 的 QR code 和網址 `trips.claire-cheng.com` 必須保留（拉新入口），QR 請放大到容易掃
- 不放個資（同行者名字、費用、訂位代號等都不出現）

## 希望拿回來的東西

1. 三種版面的改版設計（HTML/CSS 即可，720×1280）
2. 字級、間距、顏色的**具體數值規格表**（px、字重、色碼／透明度），方便工程換進 canvas
3. 內容過多／過少時的規則（字級上下限、截斷方式）
4. 至少用兩種主題色（粉紅＋一個深色或偏淡的色）驗證對比

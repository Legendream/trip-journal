## 這是什麼

旅人手帖（trips.claire-cheng.com）是一個行程 App 產生器：使用者把隨手記的行程貼進「產生器」，產出一個手機用的「行程 App」，分享給同行旅伴。行程 App 有四個分頁：行程・清單・集合・記帳（集合、記帳需要多人同步的進階模式）。

這次要新增「分組旅行」：旅伴分成幾組，有些日子分頭行動，有些日子會合一起玩。例如：

| 日期 | 鹿兒島組（🐱小貓、🐻阿熊） | 福岡組（🐟小魚、🦌阿鹿） |
|---|---|---|
| 11/1–11/2 | 鹿兒島 | （還沒出發） |
| 11/3–11/5 | 鹿兒島 | 福岡 |
| 11/6 | **會合日**：搭機到屋久島，10:20 抵達 | **會合日**：搭船到屋久島，14:00 抵達 |
| 11/6 16:00 | 全員於飯店大廳集合 | ← 同左 |
| 11/7–11/11 | 全員一起在屋久島 | ← 同左 |
| 11/12 | 留在屋久島 | **分開日**：離開屋久島回福岡 |
| 11/13 | 離開屋久島回鹿兒島 | （已離開） |

（範例中的代號、時間、集合地點都是示意資料。）

## 規則（設計時請以這些為準）

1. **每個人有一個代號**（暱稱或 emoji 都可以，不一定是真名）。組別只是把代號歸類的捷徑；有人中途換組也可以。
2. **同一天可以有好幾張日卡**：兩組在不同城市時各一張，因為住宿、天氣、當日主題都不同。
3. **會合日、分開日是一張全員日卡**，但卡片裡個別活動屬於某一組（如：「鹿兒島組 10:20 抵達」）。
4. **旅伴第一次打開行程 App，要先選自己是誰**；之後預設只看到自己的行程，可以切換看全部。這只是顯示偏好，不是保密，誰都可以看全部。
5. **會合日要讓每個人都看到別組什麼時候到**，所以別組的活動在會合日也會顯示，加上組名標籤。
6. **集合、記帳全體共用**：
   - 發起集合時可以指定通知誰（預設是發起人當天同行的人）；同一時間可以有好幾個集合，不會互相覆蓋；沒被通知的人看得到，但不會響鈴
   - 記帳只改預設勾選，不需要新畫面
7. **沒有分組的行程，畫面要跟現在一模一樣**，不能多出任何東西。

## 畫面文字（已定稿的草稿，請照用）

原則：一個元素一行字；能用標籤就不寫句子；下列以外不要再加說明文字。如果覺得哪條要改，請標出編號並說明理由。

**產生器**

| 編號 | 元素 | 文字 |
|---|---|---|
| G-1 | 問句 | 有人分頭行動嗎？ |
| G-2 | 選項（預設） | 全程一起 |
| G-3 | 選項 | 有分頭 |
| G-4 | 區塊標題（選了 G-3 才出現） | 各組成員 |
| G-5 | 提示（唯一一行說明） | 組名照草稿的寫法填，AI 才對得上 |
| G-6 | 組名欄位 placeholder | 例：福岡組 |
| G-7 | 成員欄位 placeholder | 代號或暱稱 |
| G-8 | 新增按鈕 | ＋ 再加一組 |
| M-1 | 新增成員欄位 placeholder（步驟 2） | 輸入代號或暱稱 |
| M-2 | 改代號提醒（只在修改既有行程時出現） | 改代號後，舊的記帳不會跟著改 |

**行程 App**

| 編號 | 元素 | 文字 |
|---|---|---|
| W-1 | 問句 | 你是誰？ |
| W-2 | 選項 | 各成員代號（沿用成員頭像） |
| W-3 | 略過 | 我只是看看 |
| V-1 | 切換（預設） | 我的行程 |
| V-2 | 切換 | 全部 |
| C-1 | 集合表單欄位 | 通知誰 |
| C-2 | 選項 | 各組名，以及各成員代號 |

會合日、全部檢視、別組的集合：只加組名標籤，不加句子。例如：

> 〔鹿兒島組〕10:20 搭機抵達
> 〔福岡組〕14:00 搭船抵達
> 16:00 飯店大廳集合

**不要出現在畫面上的詞**：成員代號、行程對象、集合對象、個人檢視、全部檢視、日行程。這些是規格文件內部用語。

## 限制

- 手機優先；行程 App 只在手機上使用
- 不新增分頁；行程 App 維持四個分頁
- 字型只用系統字（現行為 `-apple-system, BlinkMacSystemFont, "PingFang TC"…`），不要依賴額外的圖片檔
- 規則 7：沒有分組的行程，畫面不能有任何改變

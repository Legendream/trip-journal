# 分組旅行：設計走查報告

> 2026-10-06。由 Claude 執行，非真人可用性測試。

## 方法與限制

- 功能檢查：在瀏覽器實際操作原型 A（產生器改同行名單）、原型 B（行程 App），確認畫面與邏輯。
- 認知走查：以三種使用者角度逐步走任務——規劃行程的人（產生器）、旅途中的旅伴（App 進階版）、只拿到連結的家人（我只是看看）。
- 啟發式評估：依 Nielsen 十大原則檢查各畫面。
- 自動檢查：按鈕觸控範圍、字級、無名稱按鈕。
- 限制：設計者自己走查，抓得到流程與規則問題，抓不到「真人第一眼會不會懂」。以下標「待驗證」的項目，建議日後有機會時，請一起旅行的旅伴各點五分鐘確認。
